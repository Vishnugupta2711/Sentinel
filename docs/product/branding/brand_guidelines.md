# Sentinel Brand Guidelines

## Product Identity
**Sentinel** is an enterprise-grade AI Operating System for industrial safety and mission control. It bridges the gap between raw computer vision streams and structured industrial safety events.

The tone is:
- **Authoritative:** Commands respect and conveys extreme reliability.
- **Modern:** Feels like Gotham or Palantir—high technology, dark aesthetics, neon accents.
- **Enterprise:** Zero fluff, purely functional, high-density information architecture.

## Typography
We rely on modern, highly legible sans-serif typefaces designed for high-density interfaces.

- **Primary Typeface (UI & Headings):** *Inter*
  - Weights: Regular (400), Medium (500), SemiBold (600), Bold (700)
- **Secondary Typeface (Data & Monospace):** *JetBrains Mono* / *Roboto Mono*
  - Weights: Regular (400), Medium (500)
  - Usage: Metrics, logs, code, IDs.

## Color Palette

Our palette is strictly constrained to convey focus, urgency, and precision.

| Name | Hex Code | Usage |

| **Surface Dark** | `#111827` | Cards, panels, modals |

| **Primary Accent** | `#3B82F6` | Active states, primary buttons |
| **Neon Cyan** | `#06B6D4` | Highlighting, graphs, success |
| **Warning Orange**| `#F59E0B` | Elevated risk, warnings |

| **Text Primary** | `#F9FAFB` | Primary headings, values |

## Logo Usage
- **Primary Logo:** Text `SENTINEL` in bold tracking, accompanied by an abstract geometric hexagon or shield icon.
- **Clearance:** Minimum 24px padding around the logo.
- **Color:** Pure white (`#FFFFFF`) or light slate (`#F3F4F6`) on dark backgrounds.

## Icon Set
We utilize **Lucide Icons** across the platform for their crisp, 2px stroke, modern appearance.
- Default size: `16px` for inline, `24px` for navigation.
- Stroke width: `1.5px` to `2px`.

## Component Design Language
- **Sharp Edges:** Minimal border radius (`2px` or `4px` maximum). No rounded, bubbly shapes.
- **Borders:** Thin `1px` subtle borders (`#374151`) to separate dense information.
- **Glassmorphism:** Reserved ONLY for critical transient overlays (e.g., active alerts).
- **Shadows:** Deep, diffuse shadows purely to elevate modals above the base plane. Glows used sparingly for critical events.
